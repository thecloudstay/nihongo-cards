일본어 동사 활용, 이 5줄만 외우면 끝

동사는 세 그룹으로만 나뉩니다. 그룹 판정 → て형 5줄 → 나머지 자동. 함정 동사까지 정리했습니다.

▶ 무료로 바로 학습하기 — 설치·가입 없음

일본어 동사는 세 그룹으로만 나뉩니다. 그룹만 알면 활용은 규칙대로 붙습니다. 반대로 그룹을 모르면 평생 헷갈립니다.

1. 세 그룹 구분법

그룹다른 이름구분예
3류불규칙する / 来る 딱 둘する · 来る
2류1단동사る로 끝나고 앞이 い단·え단食べる · 見る · 起きる
1류5단동사나머지 전부書く · 話す · 待つ · 飲む
함정 주의 — る로 끝나고 앞이 い·え단인데 1류인 동사들이 있습니다. 帰る(돌아가다) · 入る(들어가다) · 走る(달리다) · 切る(자르다) · 知る(알다) · 要る(필요하다) — 이건 그냥 외워야 합니다.

2. ます형 (정중형)

  • 1류 — 어미를 い단으로 바꾸고 ます. 書く→書きます / 話す→話します
  • 2류 — る를 떼고 ます. 食べる→食べます
  • 3류 — する→します / 来る→きます (읽기가 바뀝니다)

3. て형 (가장 많이 쓰는 형)

1류가 어렵습니다. 어미별로 통째로 외우세요.

어미て형예
う·つ·る→ って買う→買って / 待つ→待って / 取る→取って
む·ぶ·ぬ→ んで飲む→飲んで / 遊ぶ→遊んで / 死ぬ→死んで
く→ いて書く→書いて
ぐ→ いで泳ぐ→泳いで
す→ して話す→話して

예외 하나 — 行く는 「行いて」가 아니라 行って입니다. 이것만 따로 외우세요.

4. ない형 (부정)

  • 1류 — 어미를 あ단으로. 書く→書かない / 飲む→飲まない
    단 う로 끝나면 わ. 買う→買わない (買あない 아님)
  • 2류 — る 떼고 ない. 食べる→食べない
  • 3류 — する→しない / 来る→こない

5. た형 (과거)

て형에서 て를 た로 바꾸면 끝입니다. 買って→買った, 飲んで→飲んだ, 書いて→書いた. て형만 제대로 익히면 た형은 공짜로 따라옵니다.

외우는 순서

  1. 그룹 판정부터 — 동사를 보면 1·2·3류가 바로 나와야 합니다. 함정 6개는 통째 암기.
  2. て형 — 가장 많이 쓰고 가장 어렵습니다. 어미 5줄을 노래처럼 외우세요.
  3. た형 — て형이 되면 자동입니다.
  4. ます·ない — 규칙이 단순해 마지막에 해도 됩니다.

자주 묻는 질문

2류인지 1류인지 어떻게 빨리 구분하나요?

る 바로 앞 글자를 보세요. い단·え단이면 2류일 가능성이 높습니다. たべる(え단), みる(い단) → 2류. のむ, かく → 애초에 る가 아니니 1류. 그리고 함정 6개(帰る·入る·走る·切る·知る·要る)만 예외로 기억하면 됩니다.

て형을 외우는 요령이 있나요?

"우쓰루 → 앗떼 / 무부누 → 은데 / 쿠 → 이떼 / 구 → 이데 / 스 → 시떼" 이렇게 리듬으로 외우면 오래 갑니다. 규칙 5줄이 전부입니다.

동사 몇 개를 알아야 하나요?

일상 대화는 300~500개면 지장이 없습니다. JLPT N3~N2 수준의 동사가 대부분 여기 들어갑니다.
